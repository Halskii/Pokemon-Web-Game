# Pokémon Battle Game

A full-stack Pokémon-style game built with React and Node.js/Express.

## Project Structure

- `/frontend` - React application
- `/backend` - Node.js/Express API server

## Getting Started

### Backend Setup
```bash
cd pokemon-game-backend
npm install
npm start
```

Server runs on http://localhost:3001

### Frontend Setup
```bash
cd pokemon-game-frontend
npm install
npm start
```

App runs on http://localhost:3000

## Features Implemented

- View Pokémon collection
- Basic battle system
- Pokémon stats and types
- Health tracking
- Move selection
- Type-based damage calculation
